# obilet.com Test Automation Project

This automation project checks the login processes and flight ticket transactions on the obilet.com website. It dynamically selects user creation and departure and return dates. It follows the Page Object Model(POM).
## Technologies Used
- **Java**: Programming language used for writing test scripts.
- **Selenium**: Framework for web application testing.
- **Cucumber**: Tool for running automated tests written in plain language.
- **Logger**: Tool for logging the test execution details.

## Project Structure
The project follows a standard Maven structure.
